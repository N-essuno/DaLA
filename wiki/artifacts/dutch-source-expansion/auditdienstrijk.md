# Dataset Card for Auditdienst Rijk

<!-- START-SHORT DESCRIPTION -->
Audit reports from the [Auditdienst Rijk](https://www.auditdienstrijk.nl/)
<!-- END-SHORT DESCRIPTION -->

The Auditdienst Rijk (ADR) audits the annual reports and financial management of the Dutch ministries. Its reports are published on [rijksoverheid.nl](https://www.rijksoverheid.nl/) and are, as works of the Dutch government, free of copyright (Auteurswet art. 15b). This dataset contains the reports as collected and cleaned for the [GPT-NL Public Corpus](https://huggingface.co/datasets/GPT-NL/GPT-NL_Public_Corpus).

## Dataset Description


<!-- START-DESC-STATS -->
- **Number of samples**: 560
- **Number of tokens (Llama 3)**: 7.16M
- **Average document length in tokens (min, max)**: 12.79K (448, 107.38K)
<!-- END-DESC-STATS -->



## Dataset Structure
An example from the dataset looks as follows.

```py
{
  "id": "auditdienstrijk_0",

  "source": "auditdienstrijk",
  "added": "2026-09-01",
  "created": "2016-01-01, 2025-12-31",
  "token_count": 7818
}
```

### Data Fields

An entry in the dataset consists of the following fields:

- `id` (`str`): A unique identifier for each document.
- `text` (`str`): The content of the document.
- `source` (`str`): The source of the document (see [Source Data](#source-data)).
- `added` (`str`): The date when the document was added to this collection.
- `created` (`str`): The date range when the document was originally created.
- `token_count` (`int`): The number of tokens in the sample computed using the Llama 3 tokenizer.
<!-- END-SAMPLE -->

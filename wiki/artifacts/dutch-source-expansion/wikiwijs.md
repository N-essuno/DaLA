# Dataset Card for Wikiwijs

<!-- START-SHORT DESCRIPTION -->
Open educational material shared by teachers on [Wikiwijs](https://www.wikiwijs.nl/)
<!-- END-SHORT DESCRIPTION -->

Wikiwijs is the Dutch national platform for open educational resources, run by
Kennisnet on behalf of the Ministry of Education, Culture and Science. Teachers
use it to build, publish and share learning material, and this subset holds the
text of what they made. It covers the full breadth of Dutch education, from
primary school through secondary and vocational education: explanations of a
topic, worked examples, exercise instructions, assignment briefs and study
guides. Documents correspond to individual pages of a learning unit, so they are
short and written in the direct, instructional register a teacher uses when
addressing a class.

## Dataset Description

## Dataset Structure
An example from the dataset looks as follows.


<!-- START-SAMPLE -->
```py
{
  "id": "wikiwijs_0",
  "text": "Some, any, much en many\nBestudeer uit de kennisbank Engels het\neerste deel\nvan het onderdeel Some, a[...]",
  "source": "wikiwijs",
  "added": "2026-09-07",
  "created": "2009-12-14, 2025-12-31",
  "token_count": 61
}
```

### Data Fields

An entry in the dataset consists of the following fields:

- `id` (`str`): A unique identifier for each document.
- `text` (`str`): The content of the document.
- `source` (`str`): The source of the document (see [Source Data](#source-data)).
- `added` (`str`): The date when the document was added to this collection.
- `created` (`str`): The date range when the document was originally created.
- `token_count` (`int`): The number of tokens in the sample computed using the Llama 3 tokenizer.
<!-- END-SAMPLE -->

## Additional Information

### Source Data

The material was collected by GPT-NL from [wikiwijs.nl](https://www.wikiwijs.nl/),
where each unit is published at a `maken.wikiwijs.nl` address, and released as
the `wikiwijs` collection of the
[GPT-NL Public Corpus](https://huggingface.co/datasets/GPT-NL/GPT-NL_Public_Corpus).

### License Information

Material on Wikiwijs is published as open educational resources under Creative
Commons Attribution terms, which permit reuse and redistribution with
attribution. GPT-NL records the licence of every document in this collection as
CC-BY.

### Limitations

Because a document is a single page of a learning unit, many are very short and
some carry little more than an instruction that points at material held
elsewhere, such as a video, an interactive exercise or an external kennisbank.
That material is not part of the dataset, so those documents do not stand on
their own. Language lessons quote extensively from the language being taught,
English most often, so the subset contains more non-Dutch text than its size
suggests. Quality is uneven, as anyone teaching in the Netherlands may publish.

### Citation Information

This dataset is derived from the [GPT-NL Public Corpus](https://huggingface.co/datasets/GPT-NL/GPT-NL_Public_Corpus). We recommend that you reference the corpus if you use this dataset. The annotations were generated by [tvosch/GPT-NL-propella-annotations](https://huggingface.co/datasets/tvosch/GPT-NL-propella-annotations).

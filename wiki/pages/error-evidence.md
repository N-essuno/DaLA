# Evidence

The W&I v2.1 A/B/C training files contain 34,308 parsed sentences. The M2 miner
found 2,393 exact case-sensitive patterns supported by at least three distinct
sentences, including 29 single-word spelling candidates. Separately inspected
LOCNESS development contained 988 parsed sentences and 28 patterns at that
threshold. This native partition is exploratory evidence, not an untouched test
set for rules informed by it. No BEA test corrections were mined.[^bea]

The initial corpus-only rulebook was built only from W&I A/B/C training. It pools lowercase
forms but deduplicates sentence support. Counts are not independent-writer counts.
Repeated edits and multiple annotators do not multiply sentence support.

# Initial lexical inventory (preserved evidence)

`config/english_rules.json` holds an explicit inventory generated by
`scripts/build_english_rulebook.py`, with evidence file hashes, counts and example
locations. There are 92 mappings: 13 spelling, 35 subject–verb agreement,
15 modal complement form, 8 do-support form, 2 perfect participle, 4 demonstrative
number, and 15 noun-number mappings. The code gates each against syntax and
source morphology. This is agent screening plus tests, not human precision review.

Spelling examples include `because → becasue`, `government → goverment`, and
`environment → envirnoment`. The reviewed inventory excludes candidate dictionary
words, names, regional alternatives, and debatable lexical changes such as
`playing → practicing`. Multi-error evidence is retained: all five observed
`confortable → comfortable` sentences have other retained edits.

For grammar, explicit contexts include full modal + base verb, auxiliary do +
base verb, perfect have + participle, demonstrative + matching adjacent common
noun, many/several + plural count noun, and personal-pronoun present agreement.
Collective-noun agreement, subjunctive/irrealis contrasts, unconstrained
preposition swaps and general homophone replacements are not enabled.

A proposed `their → there` mapping did not meet its evidence threshold and is
not enabled. Real-word spelling confusions require additional contextual evidence.

# Reproduction

Run `python -m scripts.build_english_rulebook A.train.gold.bea19.m2
B.train.gold.bea19.m2 C.train.gold.bea19.m2` from the repository root. The source
files are available via the BEA release. The repository contains rule evidence
locations and aggregates, not the original learner sentences. `dala.error_evidence`
provides a broader exploratory inventory without automatically enabling any rule.

[^bea]: BEA-2019's human-corrected corpus release; ERRANT error-type labels are automatic.

# Productive revision

The first productive English revision referenced `config/english_productive_rules.json`:
13 lexical spelling entries, four demonstrative entries, and five productive
inflection rules. The 75 earlier non-demonstrative grammatical mappings remain embedded as evidence
for these rules. Generated surface substitutions are licensed by context and
dictionary morphology rather than required to occur individually in the learner
corpus. See [architecture](/pages/pipeline-architecture.md). This change supersedes
the initial 92-exact-mapping production restriction, without changing the evidence
counts or pretending the new outputs are directly observed learner edits.

# Expanded spelling revision

The active productive rulebook now contains 72 lexical spelling mappings across
66 distinct correct word forms, plus the same nine grammar rules. Published-list
evidence is recorded separately from corpus sentence counts. See
[English spelling](/pages/english-spelling.md) for sources and screening.

The subsequent [generator revision](/pages/english-generators.md) adds three
productive character rules linked to observed spelling mechanisms and two
syntactic token fallbacks. Generated instances are explicitly synthetic; they
do not increase observed-correction counts.
